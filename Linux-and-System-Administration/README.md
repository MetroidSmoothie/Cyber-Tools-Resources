
# Linux & System Administration

A curated collection of Linux administration tools, command-line references, system monitoring utilities, and technical documentation for managing, troubleshooting, and securing Linux and Unix-based environments.

## Linux Documentation & References

| Resource | Description |
|---|---|
| [Linux Kernel Archives](https://www.kernel.org/) | Official Linux kernel releases, documentation, and development updates. |
| [Linux Manual Pages](https://man7.org/linux/man-pages/) | Comprehensive reference for Linux system calls, commands, and APIs. |
| [ArchWiki](https://wiki.archlinux.org/) | Extensive, community-maintained Linux configuration and troubleshooting documentation. |
| [Red Hat Documentation](https://docs.redhat.com/) | Enterprise Linux administration, security, networking, and system management guides. |
| [Ubuntu Server Documentation](https://documentation.ubuntu.com/server/) | Official Ubuntu Server configuration, maintenance, and administration documentation. |
| [DistroWatch](https://distrowatch.com/) | Linux distribution releases, comparisons, and development tracking. |

| Resource | Description |

## System Monitoring & Troubleshooting

| Resource | Description |
|---|---|

| [btop](https://github.com/aristocratos/btop) | System resource monitoring for CPU, memory, disk, and network activity. |
| [Sysstat](https://github.com/sysstat/sysstat) | System performance monitoring with tools such as `sar`, `iostat`, and `mpstat`. |
| [Netdata](https://www.netdata.cloud/) | Real-time infrastructure performance monitoring and diagnostics. |
| [strace](https://strace.io/) | Linux system call tracing for process and application troubleshooting. |
