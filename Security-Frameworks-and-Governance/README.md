
# Security Frameworks & Governance

## Cybersecurity Frameworks & Standards

| Resource | Description |
|---|---|
| [NIST Cybersecurity Framework (CSF)](https://www.nist.gov/cyberframework) | Risk-based framework for managing cybersecurity across Govern, Identify, Protect, Detect, Respond, and Recover functions. |
| [NIST SP 800-53](https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final) | Catalog of security and privacy controls for information systems and organizations. |
| [ISO/IEC 27001](https://www.iso.org/standard/27001) | International standard for information security management systems (ISMS). |
| [CIS Controls](https://www.cisecurity.org/controls) | Prioritized cybersecurity safeguards for improving enterprise security posture. |
| [COBIT](https://www.isaca.org/resources/cobit) | Framework for enterprise governance and management of information and technology. |
| [Cloud Security Alliance](https://cloudsecurityalliance.org/) | Cloud security frameworks, research, and industry guidance. |

## Risk Management & Assessment

| Resource | Description |
|---|---|
| [NIST Risk Management Framework (RMF)](https://csrc.nist.gov/projects/risk-management) | Structured process for categorizing systems, selecting and assessing controls, authorizing systems, and continuous monitoring. |
| [NIST SP 800-30](https://csrc.nist.gov/pubs/sp/800/30/r1/final) | Guidance for conducting organizational and system-level risk assessments. |
| [NIST SP 800-37](https://csrc.nist.gov/pubs/sp/800/37/r2/final) | Official RMF guidance for information systems and organizations. |
| [NIST SP 800-39](https://csrc.nist.gov/pubs/sp/800/39/final) | Enterprise-wide information security risk management guidance. |
| [NIST SP 800-53A](https://csrc.nist.gov/pubs/sp/800/53/a/r5/final) | Procedures for assessing implementation and effectiveness of security controls. |
| [FAIR Institute](https://www.fairinstitute.org/) | Quantitative information risk analysis methodology and resources. |

| Resource | Description |
|---|---|

| [PCI Security Standards Council](https://www.pcisecuritystandards.org/) | Payment card industry security standards, documentation, and compliance resources. |
| [NERC CIP](https://www.nerc.com/pa/Stand/Pages/CIPStandards.aspx) | Critical infrastructure protection standards for applicable bulk electric system assets. |
