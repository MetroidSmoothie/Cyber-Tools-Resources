
# Network Analysis & Utilities

## Network Analysis & Packet Inspection

| Resource | Description |
|---|---|
| [Wireshark](https://www.wireshark.org/) | Industry-standard packet capture and protocol analysis tool. |
| [tcpdump](https://www.tcpdump.org/) | Command-line packet capture and traffic inspection utility. |
| [Zeek](https://zeek.org/) | Network security monitoring and protocol-level traffic analysis. |
| [Suricata](https://suricata.io/) | Network intrusion detection, traffic inspection, and protocol analysis. |
| [Arkime](https://arkime.com/) | Large-scale packet capture, indexing, and network traffic investigation. |
| [ntopng](https://www.ntop.org/products/traffic-analysis/ntop/) | Network traffic monitoring, flow analysis, and bandwidth visibility. |

## Network Discovery & Diagnostics

| Resource | Description |
|---|---|
| [Nmap](https://nmap.org/) | Host discovery, port scanning, service identification, and network troubleshooting. |
| [Ncat](https://nmap.org/ncat/) | Network connectivity testing, data transfer, and socket troubleshooting. |
| [iperf3](https://software.es.net/iperf/) | Network throughput, bandwidth, and performance testing. |
| [MTR](https://github.com/traviscross/mtr) | Combined traceroute and ping utility for network path diagnostics. |
| [PingPlotter](https://www.pingplotter.com/) | Visual network latency, packet loss, and route troubleshooting. |
| [PRTG Network Monitor](https://www.paessler.com/prtg) | Enterprise network monitoring for availability, traffic, and infrastructure health. |
