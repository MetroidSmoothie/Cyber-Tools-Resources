
# Application Security

## Security Standards & References

| Resource | Description |
|---|---|
| [OWASP Top 10](https://owasp.org/www-project-top-ten/) | Widely adopted reference for critical web application security risks. |
| [OWASP API Security Top 10](https://owasp.org/API-Security/) | Common API security vulnerabilities and associated risks. |
| [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) | Continuously maintained secure coding and application security guidance. |
| [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) | Comprehensive methodology for testing web application security. |
| [PortSwigger Web Security Research](https://portswigger.net/research) | Ongoing research into emerging web application vulnerabilities and attack techniques. |
| [CWE](https://cwe.mitre.org/) | MITRE's maintained catalog of software and hardware weaknesses. |

## Application Security Testing Tools

| Resource | Description |
|---|---|
| [Burp Suite](https://portswigger.net/burp) | Web application and API security testing platform. |
| [OWASP ZAP](https://www.zaproxy.org/) | Open-source web application security scanner and proxy. |
| [Semgrep](https://semgrep.dev/) | Static application security testing and code analysis. |
| [Snyk](https://snyk.io/) | Dependency, code, container, and infrastructure-as-code security scanning. |
| [GitHub CodeQL](https://codeql.github.com/) | Semantic code analysis for identifying security vulnerabilities. |
| [Trivy](https://trivy.dev/) | Vulnerability and misconfiguration scanning for applications, dependencies, and containers. |
| [Nuclei](https://github.com/projectdiscovery/nuclei) | Template-based vulnerability scanning for web applications and exposed services. |
